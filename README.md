A program that writes the worst app idea ever pitched — one sentence, 151 characters — to `/output/entry.txt`. Rent-a-Grandma charges $19 an hour for a retired stranger named Brenda to call you at dinner, ask why you are still single, and hang up before dessert. It sounds real, the founder sounds certain, and nobody on earth needs it.

## Run it

```sh
python3 main.py
```
